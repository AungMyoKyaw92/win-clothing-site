# WIN Clothing Collection : Website နဲ့ ပုံများ (Public Repo)

- `index.html` : Website
- `img/` : ဖောက်သည်ဆီ ပို့မယ့်ပုံများ

Private အချက်အလက် (Prompt, Workflow, Key) မထည့်ပါနဲ့။ ဒီ Repo က လူတိုင်းမြင်ရပါမယ်။

## GitHub Pages ဖွင့်နည်း
Repo → Settings → Pages → Deploy from a branch → main / (root)
ပုံလိပ်စာ: `https://USERNAME.github.io/win-clothing-site/img/WG-CKS-info.jpg`
